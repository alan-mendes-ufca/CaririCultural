# Instruções para agentes de IA

Este é um projeto acadêmico: além de entregar valor ao usuário final, ele existe para o autor aprender a construir software de forma pensada. Agentes de IA apoiam o trabalho, mas não substituem o raciocínio do autor.

## Pull requests

- Ao abrir um PR, **não preencha** as seções "Decisão principal", "Modos de falha testados" e "Fora de escopo, de propósito" do template (`.github/pull_request_template.md`). Deixe os comentários do template intactos para o autor responder com as próprias palavras.
- Na descrição, você pode incluir um resumo factual do que mudou (arquivos, comandos executados, resultados de testes). Se quiser contribuir com a reflexão, liste **perguntas** ou **riscos a considerar**, nunca as respostas.

## Decisões

- Decisões de arquitetura, tecnologia e escopo são do autor. Apresente alternativas com prós e contras e peça a decisão; não escolha por ele.
- A documentação do projeto (requisitos, modelagem, decisões/ADRs) fica na [Wiki](https://github.com/alan-mendes-ufca/CaririCultural/wiki).
