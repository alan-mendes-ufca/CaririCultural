### Épico 1: Exploração e Descoberta

| id     | historia                                                                                                                                                                                                                                                          |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="HU-001"></a>HU-001 | Como usuario, quero **consultar um catalogo regional** de lugares turisticos, culturais, gastronomicos, comerciais e de lazer, para descobrir novas opcoes de passeio, consumo e experiencia.                                                                     |
| <a id="HU-002"></a>HU-002 | Como usuário, quero ter acesso a uma **lista de localidades que estão sendo muito visitadas**, para que eu possa descobrir tendência que estão acontecendo na região.                                                                                             |
| <a id="HU-003"></a>HU-003 | Como usuário, quero ter acesso a uma **lista de localidades pouco divulgadas**, para explorar a regiao alem das opcoes menos conhecidas.                                                                                                                          |
| <a id="HU-004"></a>HU-004 | Como usuário, quero **pesquisar locais e eventos por palavras-chave**, nome, categoria ou cidade **e receber orientações claras com sugestões alternativas quando não houver resultados**, para encontrar o que procuro ou descobrir alternativas sem frustração. |
| <a id="HU-005"></a>HU-005 | Como usuario, quero **filtrar locais e eventos por categoria e adequacao ao publico**, incluindo opcoes para criancas e familia, para escolher destinos compativeis com minha necessidade.                                                                        |

### Épico 2: Informações e Detalhes do Local

| <a id="HU-010"></a>HU-010 | Como usuário, quero **consultar informações de segurança do local**, para visitar o destino com mais confiança.                                                                                                           |

| <a id="HU-039"></a>HU-039 | Como usuário, quero **consultar o formato de serviço do local** (atendimento na mesa, self-service, rodízio com garçom, rodízio com fila, balcão, etc.), para não ser surpreendido pela dinâmica do estabelecimento.      |

### Épico 7: Interações Sociais e Compartilhamento

| id     | historia                                                                                                                                                                                                        |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="HU-034"></a>HU-034 | Como usuário, quero **criar uma enquete rápida com opções de locais/eventos e compartilhar o link com amigos (que podem votar sem precisar de login)**, para facilitar a decisão em grupo de forma ágil.        |
| <a id="HU-035"></a>HU-035 | Como usuário sem transporte próprio, quero ter **acesso a uma rede de contatos de transportes alternativos locais recomendados**, para conseguir me deslocar com economia e segurança durante eventos noturnos. |
| <a id="HU-036"></a>HU-036 | Como usuário, quero **visualizar fotos e vídeos reais (formato reels/stories) publicados por outros visitantes**, para ter uma visão autêntica do ambiente e não criar expectativas irreais.                    |
| <a id="HU-037"></a>HU-037 | Como usuário mais experiente na região, quero **criar e compartilhar listas de "rolês favoritos" com amigos externamente**, para facilitar a experiência de quem ainda não conhece a cidade.                    |
